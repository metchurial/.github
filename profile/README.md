Treating queries as data.

🥚 **metchurial** reads Db2, PostgreSQL and Spark SQL and reports what each statement reads and writes; metchurial-js brings these and T-SQL to the browser.

🥖 **paris-parquet** runs SQL over parquet. Open one HTML file on your laptop, or run it as a server your team shares.
